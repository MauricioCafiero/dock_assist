# metal-site docking (dock_metal_site_agent): meeko preps receptor/ligand PDBQTs
# for the AD4Zn path; gemmi + prody are meeko's receptor-prep dependencies.
# Covalent docking (dock_covalent_agent) needs the same three, and prody is
# REQUIRED there specifically: meeko's covalent tether path
# (mk_prepare_ligand.py --receptor/--rec_residue/--tether_smarts) imports prody
# and refuses to run without it. Don't drop prody as "metal only".
# Covalent docking additionally needs the AutoDock4 binary -- not a pip
# package; see README "Installation".
# meeko is pinned on purpose. The covalent path drives its CLI directly --
# mk_prepare_receptor.py -f/-p/--allow_bad_res/--default_altloc and
# mk_prepare_ligand.py --receptor/--rec_residue/--tether_smarts -- and those
# flags have moved between meeko releases. An unpinned meeko can break
# covalent docking with confusing errors. Tested with 0.8.0.
